# TG 腳本製作流程

請嚴格照這個流程產出短影音腳本：

## 1. HERMES 判斷

先用藏鏡人角度判斷：

- 這支影片真正要解決什麼觀眾問題？
- 品牌原本想講的話哪裡太像廣告？
- 哪一句可以變成觀眾心裡 OS？
- 這支片最適合用哪種互動形式？

## 2. 現場模擬

先模擬 2 到 3 個角色在現場講話。

常用角色：

- 品牌主：想介紹自己，但容易講成公司簡介。
- 觀眾 / 客戶：有疑問、懷疑、卡住、不知道為什麼要相信。
- 藏鏡人：拆出真正問題，逼近可拍攝腳本。

每句模擬要有：

- speaker
- line
- innerOS
- purpose

## 3. 真人句

從模擬中抽出 3 到 8 句能直接放進短影音的真人句。

真人句標準：

- 短。
- 像人講話。
- 有情緒或反差。
- 能推動衝突。
- 不像簡報。

## 4. 故事骨架

建立：

- hook
- setup
- conflict
- turningPoint
- ending

## 5. 腳本草稿

每段必須有：

- time
- speaker
- visual
- audio

audio 必須是可直接拍攝/配音的台詞，不可只是「整理服務重點」。

## 6. 人話檢查

檢查：

- 是否 AI 腔？
- 是否像公關稿？
- 是否只有陳述沒有衝突？
- 是否有角色互動？
- 是否踩到禁語或誇大承諾？
